```text
https://raw.githubusercontent.com/violin321/extensions/repo/index.min.json
```

## Updating in Suwayomi

After a new version is published:

1. Refresh extension repositories.
2. Update the extension if Suwayomi shows an update.
3. If Suwayomi keeps using an old APK, uninstall the extension and reinstall it from this repository.
